# UI 이미지 사용

현재 게임은 이미지 교체 전 디자인을 사용합니다.

- 시작: `기타이미지11.png`
- 점수: `기타이미지12.png`
- 게임 종료 패널: `기타이미지13.png`
- 체력: `기타이미지14.png`
- 플레이 중 멈춤 아이콘: `기타이미지15.png`
- 일시정지 중 아이콘: `멈춤버튼.png` (667×711, RGBA PNG)
- 재도전: 기존 CSS 버튼과 `다시 도전하겠소` 문구

`멈춤버튼.png`는 `멈춤버튼.jpg`(667×711)의 외곽 체크무늬를 알파로 제거한 파생 파일입니다. 원본 JPEG는 보존합니다. PNG를 미리 불러와 일시정지 중에만 표시하고 재개/재시작 시 원래 기타이미지15 PNG로 복귀합니다. 파생 PNG 로딩 실패 시에도 원래 아이콘을 유지합니다. 두 아이콘은 기존65:67 버튼 상자에서 contain으로 표시합니다. `성적공개.jpg`(852×502), `재시도버튼.jpg`(651×769), `다시 시작 버튼.jpg`는 보관하며 게임에서는 사용하지 않습니다. 업로드 이미지 파일은 삭제하거나 수정하지 않았습니다.

기타이미지13 PNG에는 `게임 오버`, `최종 점수`, `12,345`, 파란 `다시하기` 버튼이 인쇄되어 있습니다. 원본 파일을 수정하지 않고 CSS의 독립된 종이색 영역으로 이 세 구역을 가립니다. 새 텍스트와 버튼의 크기나 위치에 의존해 옛 인쇄 부분을 덮지 않습니다. 테두리와 상단 캐릭터는 유지합니다.

배경 제거는 원본 RGB를 그대로 복사하고 알파 채널만 추가하는 방식입니다. 꽃잎과 내부 밝은 부분은 보호했고 외곽의 저채도 JPEG 매트 한 픽셀만 제거한 뒤 알파 경계를 처리했습니다. 불투명 픽셀261,483개의 RGB와 내부 밝은 픽셀8,947개가 보존됨을 검사했습니다. 원본과 파생 파일의 SHA-256 및 처리 통계는 `tools/pause-icon-processing-report.json`에 있습니다.

재현: `node tools/prepare_pause_icon.cjs` (개발용 sharp 필요). 게임 실행에는 Node나 서버 처리 과정이 필요하지 않습니다.

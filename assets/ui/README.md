# 현재 UI 이미지

| 용도 | 경로 | 원본 크기 | 형식 |
|---|---|---|---|
| 멈춤 | `멈춤버튼.jpg` | 667×711 | JPEG / RGB |
| 성적 공개 | `성적공개.jpg` | 852×502 | JPEG / RGB |
| 재도전 | `재시도버튼.jpg` | 651×769 | JPEG / RGB |

세 파일은 사용자 업로드 원본 그대로 사용합니다. 모두 실제 알파 채널이 없으며 회색/흰색 체크무늬가 RGB 픽셀에 포함되어 있습니다. 임의로 지우거나 색을 변경하지 않습니다. 체크무늬 없는 표시에는 실제 투명 PNG 파일이 필요합니다.

성적 공개에는 인쇄된 문구가 없어 제목·안내·점수를 HTML로 중앙에 표시합니다. 재시도에는 회전 화살표만 있어 `다시 도전하겠소`를 이미지 아래에 한 번 표시합니다. 멈춤 파일의 삼각형 기호 역시 원본 그대로 쓰되 버튼 기능과 접근성 이름은 일시정지입니다.

`다시 시작 버튼.jpg`와 이전 HEIC/PNG 파일들은 보존하며 이번 교체에는 사용하지 않습니다. 기존 시작·점수·체력 이미지는 각각 기타이미지11·12·14 PNG를 유지합니다.

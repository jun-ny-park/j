# 유생런

HTML / CSS / JavaScript와 Canvas로 만든 조선 유생의 2D 자동 달리기 게임입니다. 외부 라이브러리나 서버가 필요 없습니다. `index.html`을 브라우저에서 열어 실행합니다.

## 조작과 규칙

- 시작 버튼 또는 스페이스바로 시작합니다.
- 스페이스바, 게임 화면 터치 또는 모바일 점프 버튼으로 점프합니다. 공중에서 추가 점프는 불가능합니다.
- 귤 하나에 100점. 기차 장애물에 부딪히면 체력이 1 감소합니다.
- 체력은 3이며, 충돌 후 1.35초간 무적입니다. 체력이 0이면 게임 오버와 다시 시작 버튼이 표시됩니다.
- 우측 상단 버튼 또는 Esc로 일시 정지/계속하기. 다른 탭으로 이동하면 자동 일시 정지됩니다.
- 진행할수록 속도가 조금씩 증가하며 최고 속도는 제한됩니다.

## PNG 추가

아래 위치에 이미지를 추가하고 새로 고침하세요. `game.js`의 `ASSET_PATHS`에서 경로를 바꿀 수도 있습니다. 각 이미지는 독립적으로 로드됩니다. 누락되거나 손상된 파일은 자동으로 Canvas 도형으로 대체합니다. 로딩 완료를 기다리지 않고 게임을 실행합니다.

| 용도 | 경로 | 권장 비율 |
|---|---|---|
| 갓·도포 유생 | `assets/characters/yusaeng.png` | 76:96, 투명 배경 |
| 귤 | `assets/items/orange.png` | 1:1, 투명 배경 |
| 기차 장애물 | `assets/obstacles/train.png` | 78:51, 투명 배경 |
| 이어지는 배경 | `assets/backgrounds/background.png` | 가로형, 좌우 가장자리가 이어지는 타일 |

배경은 높이 480의 게임 좌표계에 맞춰 비율을 유지하고 반복 스크롤합니다. 캐릭터·귤·기차는 고정된 표시 영역에 맞춰집니다. 이미지 교체는 충돌 판정을 변경하지 않습니다. 배경의 바닥 위쪽(높이 385까지)에 주요 풍경을 배치하세요. 현재는 단일 PNG이며 스프라이트 애니메이션은 포함하지 않습니다.

## GitHub Pages

저장소 Settings → Pages → Build and deployment에서 **Deploy from a branch**, **main**, **/(root)**를 선택해 저장하세요. Pages를 사용할 수 있는 저장소/요금제여야 합니다. 모든 경로가 상대 경로이므로 프로젝트 Pages의 `/j/` 하위에서도 동작합니다. 예상 주소는 `https://jun-ny-park.github.io/j/`이며 Pages 활성화 후 사용할 수 있습니다.

파일: `index.html`, `style.css`, `game.js`. 빌드/설치/서버 설정은 필요하지 않습니다.

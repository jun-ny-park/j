# 유생런

귤을 찾아 떠나는 특별한 과거시험.

**플레이:** https://jun-ny-park.github.io/j/

HTML/CSS/JavaScript Canvas 게임입니다. 빌드·게임 서버·외부 폰트 서비스 없이 동작하며 GitHub Pages의 상대 경로 구조를 유지합니다.

## 최신 변경

- 배경: `assets/backgrounds/bbaakk1.jpg` 한 장을 원본 비율로 반복. 렌더링에만 블러 1.25 CSS px·채도 93%·대비 93%를 적용해 수집 아이템과 구분. 기존 배경들은 로드하지 않음.
- 하단의 마을→황감제 문구 제거. 거리는 우측에 유지.
- 장애물: 기타이미지1·5·6·7·9와 야호1~4의9종. 1·5·야호2·야호3은1단, 6·7·9·야호1·야호4는2단 점프용. 기타이미지2는 파일만 보관.
- 귤: `귤1.jpg`~`귤6.jpg` 원본을 보존하고 투명 RGBA PNG 6개 추가. 새 PNG만 수집 아이템으로 사용.
- 붓: 실제 플레이 시간 기준 최소 36초 생성 간격. 난이도가 높아져도 빈도가 올라가지 않음.
- 붓 가속: 5초, 기본 속도의 1.5배. 마지막 0.25초 안에서 부드럽게 기본 속도로 복귀. 재획득은 시간만 갱신.
- 과거 책(기타이미지3): 5초 거대화. 약 1.5배로 부드럽게 커지고 작아지며 발 위치는 유지.
- 거대화 중에는 피해를 받지 않고 모든 장애물을 파괴. 일반 피해 몸통은 그대로이며, 파괴용 접촉 영역만 커진 캐릭터에 맞춤.
- 효과 UI: 파란 단선 테두리는 가속, 황금색 이중 테두리는 거대화. 각각 남은 초만 표시. 접근성 이름으로 효과를 구분.
- 일시정지: **잠시 쉬어가게나 / 다시 달려보세**. 버튼 하나로 모든 상태를 보존해 이어하기.

## 조작

- Space / 화면 터치: 최대 2단 점프. 착지하면 횟수 초기화
- 귤 하나: +100점
- 붓: 5초 가속, 과거 책: 5초 거대화
- 정지 버튼 / Esc: 일시정지. 탭 전환 시 자동 정지
- 결과 화면의 다시 도전하겠소: 점수·체력·아이템·점프 상태 초기화

기준 속도 306px/s에 기존 시간별 1.25~2.0배와 5,000점부터 1.15배/10,000점부터 1.30배를 한 번씩 적용합니다. 일반/거대화 단독 점프는 그대로이며, 가속 중에는 최고 높이와 2단 점프를 유지하면서 체공시간만 짧아집니다. 두 아이템 타이머와 난이도 시간은 일시정지 중 모두 멈춥니다.

## 남은 사항

`bbaakk1.jpg`는 좌우 구름·다리 윤곽이 완전히 같지 않아 반복 경계가 일부 보입니다. 빈 띠·겹침·위치 점프는 없지만 원본 그림의 차이는 그대로 유지합니다. 실물 iOS/Android 기기와 Safari는 미검증입니다.

## 배경과 플레이 요소의 시각적 위계

`game.js` 상단의 `BACKGROUND_STYLE`에서 강도를 조정할 수 있습니다.

```js
const BACKGROUND_STYLE = { blurPx: 3, saturation: .83, contrast: .88 };
```

`blurPx`는 실제 화면 CSS 픽셀, 채도와 대비의 `1`은 원래 강도입니다. `0 / 1 / 1`로 설정하면 효과 없이 표시됩니다. 고해상도 화면의 DPR도 반영합니다.

화면 크기나 필터가 바뀔 때 한 주기의 배경을 이어 붙여 필터 결과를 캐시합니다. 평소 프레임에서는 이 캐시를 스크롤해서 복사하며 필터를 다시 계산하지 않습니다. 화면 밖에 샘플링 여유를 두어 블러의 투명 테두리와 타일 이음새를 방지합니다. 필터는 캐시 전용 컨텍스트의 `finally`에서 `none`으로 해제하며 메인 Canvas는 항상 필터 없이 그립니다. 캐릭터·귤 6종·장애물·붓·거대화 아이템·UI는 필터 없이 표시하고, 귤의 아이보리 외곽선·반짝임과 검증된 점프 경로는 유지합니다. 원본 bbaakk1 파일과 다른 이미지 파일은 수정하지 않습니다.

## 점진적 난이도

최초 기준 속도 306px/s에 0–10초 1.25배, 10–20초 1.45배, 20–35초 1.65배, 35–50초 1.85배, 이후 최대 2.0배를 한 번만 적용합니다. 0초부터 1.25배이며 경계에서는 1.5초 동안 부드럽게 증가합니다. 시간 제한이나 난이도 안내 문구는 없습니다.

초반 단독·2개 연속, 10초 이후 2단 장애물, 20초 이후 교차, 35초 이후 3~4개 연속이라는 기존 재료를 유지합니다. 기본/연속/긴장/귤 보너스/짧은 휴식의5개 틀을 전용 난수로 선택하며, 같은 패턴·실제 배열의3연속과 보너스/휴식 연속을 막습니다. 보너스/휴식은 기존 틀에서 장애물을 생략합니다. 장애물이 전혀 없는 귤 전용 보너스는 기존 X간격을 유지한 채 공중/낮은 높이 중 하나의 수평 줄로 만듭니다. 혼합 구간과 휴식 구간의 원래 아치는 유지합니다. 붓·책은 드물게 기존 귤 한 자리를 대체합니다. 아이템 때문에 추가하던 긴 휴식 간격은 제거했고, 기존 일반 상태의 좁힌 간격(78% 목표+안전 하한)을 고정합니다. 아이템 감지/획득/만료로 간격을 확장하지 않습니다. 장애물 빈도 우선 선택에 따라 공통 아이템 생성 주기도 함께 짧아집니다. 귤의 높이·크기·배열은 유지하며 아치 내부 월드 간격에는 붓과 점수 배율을 적용하지 않습니다.

5,000점/10,000점의 추가 배율은 1.5초 동안 부드럽게 전환됩니다. 가속 중 점프 시계는 실제 가속/일반 속도 비율로 빠르게 진행해 최고 높이를 유지하면서 착지 공간을 확보합니다. 생성 경계의 잔여 이동 거리도 이월합니다. 붓은 5초간 최대 1.5배이며 전체 최대 속도는 1,193.4px/s입니다. 아주 좁은 창에는 기존 시야 안전 상한이 우선합니다. 모바일 실제 가로 화면에서는 제목과 부제가 두 줄로 중앙 정렬됩니다. PC와 세로 접속의 기존 CSS 회전 설정은 유지합니다.

## 거대화 장애물 파괴와 포즈 정리

과거 책으로 거대화한 5초 동안 지정한9종 장애물을 점프 없이 돌파합니다. 렌더링된 캐릭터와 장애물 코어의 실제 불투명 픽셀이 겹친 장애물만 파괴합니다. 만료 시 근처 물체를 미리 파괴하지 않습니다. 파괴된 장애물은 즉시 충돌에서 빠지고, 원본 그림 그대로 오른쪽 위로 회전·축소·투명해지며 0.6초 안에 퇴장합니다. 별도 폭발 이미지를 추가하지 않고 작은 먼지 3개와 별 2개만 순간 표시합니다. 장애물 파괴 점수는 따로 추가하지 않아 귤 점수 계산은 그대로입니다.

거대화 시작에는 짧은 확대 효과, 지상 달리기에는 약간 힘찬 발걸음과 작은 먼지를 적용합니다. 마지막 1초에는 3회 은은하게 반짝이며 완전 투명해지지 않습니다. 만료하면 일반 피해 판정으로 즉시 복귀하고 크기는 부드럽게 줄어듭니다. 일시정지하면 아이템 시간·퇴장 애니메이션·먼지·반짝임이 함께 멈춥니다.

캐릭터 6·7번은 슬라이딩 포즈라 로딩과 모든 상태에서 제외했습니다. 달리기 1·2·3·4·5·9, 상승 점프 8, 하강 1, 피격 5, 게임 오버 2를 명시적으로 사용합니다. 원본 6·7 PNG/HEIC는 삭제하지 않았습니다. 특정 포즈의 로딩이 실패해도 남아 있는 정상 프레임으로 표시해 빈 프레임을 방지합니다.

## 거대화 수집 판정 수정

캐릭터 렌더링과 아이템 수집은 같은 `characterGeometry()` 계산을 공유합니다. 실제 포즈의 비율·확대/축소·발걸음·착지 변형과 투명 여백을 반영하고, 작은 안티앨리어싱 여유를 더해 몸에 닿은 귤/붓/과거 책을 수집합니다. 거대화 만료 후에도 보이는 축소 크기에 맞춰 자연스럽게 일반 크기로 돌아갑니다.

일반 피해 몸통(`damageBox`)과 거대화 장애물 파괴 영역(`destructionBox`)은 수집 영역(`collectionBox`)과 분리돼 있습니다. 거대화의 파괴·무적과 기존 난이도는 유지합니다. 이미 수집한 물체는 즉시 처리 목록에서 제거해 중복 득점을 방지합니다.

난이도 안내용 DOM/CSS/문구/1초 타이머는 제거했습니다. 이미지 파일, 수채화 디자인, 점수·체력·두 아이템 시간 UI는 변경하지 않았습니다.

## 일시정지와 결과 패널

일시정지는 **잠시 쉬어가게나 / 다시 달려보세**로 표시하며 이어하기 동작은 그대로입니다. 결과 패널은 **황감제 결과 발표 → 그대의 성적은? → 실제 점수+점 → 다시 도전하겠소** 순서입니다. 안내와 점수는 기존 수채화 패널 중앙의 같은 영역에 배치하고, 긴 점수는 중심을 유지하면서 글자 크기를 조정합니다.

종료 패널은 `assets/ui/기타이미지13.png`, 멈춤은 `assets/ui/기타이미지15.png`, 재도전은 기존 파란 버튼 디자인을 사용합니다. 두루마리 원본에 인쇄된 옛 제목·예시 점수·버튼은 각각 독립적인 불투명 종이색 마스크로 가립니다. 제목은 교체 전 커밋 `9743ff5`처럼 상단 유생 그림 오른쪽에 두고, 안내·굵은 실제 점수·타원형 재도전 버튼은 두루마리 중앙에 배치합니다. 원본 비율을 유지하며 전체 이미지와 글씨를 함께 확대/축소합니다. 패널은 하나이며 종료 시 실제 점수를 한 번만 갱신합니다. `멈춤버튼.png`는 원본 JPG의 외곽 체크무늬만 제거한 RGBA 파일로 일시정지 중에만 표시하고, 플레이/재시작 시 원래 기타이미지15 PNG로 돌아옵니다. 버튼의 고정 비율과 터치 영역은 유지하며 새 PNG 로딩 실패 시 원래 아이콘을 사용합니다. 원본 `멈춤버튼.jpg`는 보존합니다. `성적공개.jpg`·`재시도버튼.jpg`는 보관하고 사용하지 않습니다. 이어하기·재도전 버튼의 시각 크기는 약18% 축소하고 최소44px 터치 영역을 확보합니다. 체력 숫자는 실제 게이지 트랙과 같은 영역에서 중앙 정렬합니다.

## 모바일 가로 레이아웃

터치 전용 모바일 화면(최대 1024px 폭)에서는 전체 UI가 가로 레이아웃을 사용합니다. 세로 접속 시 `main`을 CSS로 90도 회전하고, 실제 가로 전환 시 회전을 해제합니다. 점수·체력·거리·아이템 시간·시작/일시정지/결과 화면이 함께 회전합니다. 회전 안내나 강제 전체화면 권한은 필요하지 않습니다.

동적 뷰포트 단위와 기기의 안전 영역을 적용하며, Canvas는 변환 전 CSS 크기로 논리 폭·해상도를 계산합니다. 화면 터치는 브라우저의 변환된 요소 판정을 그대로 사용하므로 별도 수동 좌표 변환이나 이중 회전이 없습니다. PC의 일반 마우스 화면은 기존 레이아웃을 유지합니다.

## 고속 렌더링과 프레임 보호

배경 블러·색보정과 아이템 외곽선을 크기별로 미리 합성해 재사용합니다. 화면 밖 오브젝트는 그리지 않고 통과한 오브젝트는 제거합니다. 장애물의 알파 충돌은 랜덤화 이전의 원본 픽셀 검사로 복구했으며, HUD는 값이 바뀔 때만 갱신합니다. DPR 최대2와 약300만 픽셀 상한을 사용합니다.

정상 프레임은 실제 delta time으로 진행하고 충돌은 최대1/120초씩 나눠 검사합니다. 100ms를 넘는 긴 프레임 공백은 기존 일시정지 화면으로 보호하며, 재개 시 누적 시간을 한꺼번에 따라잡지 않습니다. 속도·난이도 배율과 두 특수 효과의5초 지속 시간은 유지합니다.

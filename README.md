# 유생런

귤을 찾아 떠나는 특별한 과거시험.

**플레이:** https://jun-ny-park.github.io/j/

HTML/CSS/JavaScript Canvas 게임입니다. 빌드·게임 서버·외부 폰트 서비스 없이 동작하며 GitHub Pages의 상대 경로 구조를 유지합니다.

## 최신 변경

- 배경: `assets/backgrounds/bbaakk1.jpg` 한 장을 원본 비율로 반복. 렌더링에만 블러 1.25 CSS px·채도 94%·대비 94%를 적용해 수집 아이템과 구분. 기존 배경들은 로드하지 않음.
- 하단의 마을→황감제 문구 제거. 거리는 우측에 유지.
- 장애물: 기타이미지1·2·6·7·9만 사용. 6·7·9는 2단 점프 경로에 배치.
- 귤: `귤1.jpg`~`귤6.jpg` 원본을 보존하고 투명 RGBA PNG 6개 추가. 새 PNG만 수집 아이템으로 사용.
- 붓: 실제 플레이 시간 기준 최소 36초 생성 간격. 난이도가 높아져도 빈도가 올라가지 않음.
- 붓 가속: 5초, 기본 속도의 1.5배. 마지막 0.25초 안에서 부드럽게 기본 속도로 복귀. 재획득은 시간만 갱신.
- 과거 책(기타이미지3): 5초 거대화. 약 1.5배로 부드럽게 커지고 작아지며 발 위치는 유지.
- 거대화 중에는 피해를 받지 않고 모든 장애물을 파괴. 일반 피해 몸통은 그대로이며, 파괴용 접촉 영역만 커진 캐릭터에 맞춤.
- 효과 UI: 파란 단선 테두리는 가속, 황금색 이중 테두리는 거대화. 각각 남은 초만 표시. 접근성 이름으로 효과를 구분.
- 일시정지: **잠시 쉬어가게나 / 다시 달리기**. 버튼 하나로 모든 상태를 보존해 이어하기.

## 조작

- Space / 화면 터치 / 모바일 점프 버튼: 최대 2단 점프. 착지하면 횟수 초기화
- 귤 하나: +100점
- 붓: 5초 가속, 과거 책: 5초 거대화
- 정지 버튼 / Esc: 일시정지. 탭 전환 시 자동 정지
- 게임 오버의 다시 도전하기: 점수·체력·아이템·점프 상태 초기화

기본 속도는 306px/s에서 시간에 따라 최대 1.28배로 올라갑니다. 수직 점프 물리는 모든 단계와 가속 상태에서 실제 시간으로 동일하게 동작합니다. 두 아이템 타이머와 난이도 시간은 일시정지 중 모두 멈춥니다.

## 이미지 보존

배경·캐릭터·장애물·UI 원본과 JPG 귤 6개는 수정하지 않았습니다. 귤의 흰 배경만 분리한 파생 PNG를 추가했습니다. 불투명한 그림 내부의 RGB는 원본과 동일하며, 투명해지는 가장자리는 흰 배경 혼합색을 보정했습니다. 원본의 크림색 그림 테두리와 내부 흰 하이라이트는 보존했습니다.

## 남은 사항

`bbaakk1.jpg`는 좌우 구름·다리 윤곽이 완전히 같지 않아 반복 경계가 일부 보입니다. 빈 띠·겹침·위치 점프는 없지만 원본 그림의 차이는 그대로 유지합니다. 실물 iOS/Android 기기와 Safari는 미검증입니다.

## 배경과 플레이 요소의 시각적 위계

`game.js` 상단의 `BACKGROUND_STYLE`에서 강도를 조정할 수 있습니다.

```js
const BACKGROUND_STYLE = { blurPx: 1.25, saturation: .94, contrast: .94 };
```

`blurPx`는 실제 화면 CSS 픽셀, 채도와 대비의 `1`은 원래 강도입니다. `0 / 1 / 1`로 설정하면 효과 없이 표시됩니다. 고해상도 화면의 DPR도 반영합니다.

반복 타일을 별도 배경 버퍼에서 먼저 이어 붙인 뒤 배경 한 레이어에만 필터를 적용합니다. 화면 밖에 샘플링 여유를 두어 블러의 투명 테두리와 타일 이음새를 방지합니다. 필터는 `save/restore`와 `finally`의 `filter = 'none'`으로 해제합니다. 캐릭터·귤 6종·장애물·붓·거대화 아이템·UI는 필터 없이 표시하고, 귤의 아이보리 외곽선·반짝임과 검증된 점프 경로는 유지합니다. 원본 bbaakk1 파일과 다른 이미지 파일은 수정하지 않습니다.

## 점진적 난이도

0–20초 쉬움(1.0배), 20–45초 보통(1.08배), 45–75초 어려움(1.16배), 75–110초 도전(1.23배), 이후 고수(최대 1.28배)입니다. 각 경계에서는 3초 동안 부드럽게 목표 속도로 증가합니다.

초반 단독 1단 장애물에서 중반 혼합, 후반 2~3개 연속 조합으로 발전하며 간격도 좁아집니다. 간격은 최대 합산 속도와 실제 체공·착지 시간에서 계산합니다. 좁은 모바일에서는 시야에 맞춰 붓의 추가 속도를 제한합니다. 큰 팝업 없이 작은 1초 안내만 표시합니다.

## 거대화 장애물 파괴와 포즈 정리

과거 책으로 거대화한 5초 동안 장애물 1·2·6·7·9를 점프 없이 돌파합니다. 파괴된 장애물은 즉시 충돌에서 빠지고, 원본 그림 그대로 오른쪽 위로 회전·축소·투명해지며 0.6초 안에 퇴장합니다. 별도 폭발 이미지를 추가하지 않고 작은 먼지 3개와 별 2개만 순간 표시합니다. 장애물 파괴 점수는 따로 추가하지 않아 귤 점수 계산은 그대로입니다.

거대화 시작에는 짧은 확대 효과, 지상 달리기에는 약간 힘찬 발걸음과 작은 먼지를 적용합니다. 마지막 1초에는 3회 은은하게 반짝이며 완전 투명해지지 않습니다. 만료하면 일반 피해 판정으로 즉시 복귀하고 크기는 부드럽게 줄어듭니다. 일시정지하면 아이템 시간·퇴장 애니메이션·먼지·반짝임이 함께 멈춥니다.

캐릭터 6·7번은 슬라이딩 포즈라 로딩과 모든 상태에서 제외했습니다. 달리기 1·2·3·4·5·9, 상승 점프 8, 하강 1, 피격 5, 게임 오버 2를 명시적으로 사용합니다. 원본 6·7 PNG/HEIC는 삭제하지 않았습니다. 특정 포즈의 로딩이 실패해도 남아 있는 정상 프레임으로 표시해 빈 프레임을 방지합니다.

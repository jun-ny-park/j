# 유생런 · 황감제를 향해!

직접 제작한 수채화·종이 질감의 그림을 사용하는 Canvas 2D 자동 달리기 게임입니다.

**플레이:** https://jun-ny-park.github.io/j/

`index.html`을 브라우저에서 열거나 정적 호스팅에 올리면 실행됩니다. 빌드, 외부 라이브러리, 게임 서버가 필요 없습니다. 저장소의 기존 GitHub Pages 설정과 상대 경로를 유지합니다.

## 조작

- 시작하기 또는 Space로 시작
- Space / 게임 화면 터치 / 모바일 점프 버튼으로 점프 (공중 추가 점프 불가)
- 귤과 귤 조각 수집: 각 100점
- 기차·바위·울타리·항아리 충돌: 체력 1 감소, 1.4초 무적
- 체력 0: 최종 점수와 다시하기
- 정지 버튼 / Esc: 일시 정지, 다른 탭으로 이동해도 자동 정지
- 진행에 따라 속도가 올라가며 최대 속도는 제한됨

## 그림 적용

전체 이미지 목록과 용도, 해상도는 [ASSETS.md](ASSETS.md)에 기록했습니다. HEIC 원본 32장은 삭제하거나 수정하지 않았으며, 같은 폴더에 같은 이름의 `.png`를 추가했습니다. 기존 배경 4장은 대문자 `.PNG` 경로를 그대로 사용합니다.

- 픽셀 크기·RGBA·투명도를 유지해 변환 (pillow-heif 1.8.1 / Pillow 13.0.0)
- HEIC 디코딩 결과와 PNG의 픽셀 데이터 일치 검증: 32/32
- 캐릭터는 실제 동작별 이미지로 애니메이션, 모든 이미지는 비율을 유지해 표시
- 배경은 화면 높이에 비례해 확대하고 130 게임 좌표 폭의 경계를 겹쳐 전환. 원본 배경은 수정하지 않음
- UI 예시 숫자는 원본을 수정하지 않고 HTML 숫자로 덮어 실제 점수 표시. 체력바는 실제 체력 비율로 표시
- 이미지 로딩 실패 시 파일 경로를 화면과 콘솔에 표시. 필수 캐릭터·귤·배경이 없으면 시작을 막고, 임의의 대체 이미지는 생성하지 않음

## 검증

Chromium / Playwright에서 PC 1280×900 및 모바일 390×844로 실행했습니다. 이미지 36개 로딩, 점프, 귤 수집, 충돌 체력 감소, 게임 오버, 재시작 초기화, 일시 정지 중 거리 고정, 모바일 입력, 가로 넘침 없음, JavaScript 오류 없음 확인. 세부 결과는 [TESTING.md](TESTING.md)를 참고하세요.

## 남은 개선 여지

- 원본 캐릭터·UI는 약 58~241px 크기라 큰 화면에서는 확대가 보입니다. 고해상도 원본이 있다면 더 선명해집니다.
- 배경 네 장은 서로 다른 구도여서 경계 겹침 부분에 잠깐 풍경이 중첩됩니다. 완전한 무봉제 연결은 이어지는 전용 배경 원본이 있으면 개선됩니다.
- 게임 오버/점수판 이미지에 예시 숫자가 포함돼 있어 해당 영역은 단색 바탕 위 실제 숫자로 표시합니다. 숫자를 비운 원본이 있으면 질감을 더 자연스럽게 유지할 수 있습니다.
- 실물 iOS/Android 기기와 Safari는 아직 검증하지 않았습니다.

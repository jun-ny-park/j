# 유생런

귤을 찾아 떠나는 특별한 과거시험. 기존 수채화 그림을 사용하는 Canvas 2D 러너입니다.

**플레이:** https://jun-ny-park.github.io/j/

HTML/CSS/JavaScript만으로 실행합니다. 빌드·게임 서버·외부 폰트 서비스가 필요 없습니다. GitHub Pages의 기존 상대 경로 구조를 유지합니다.

## 4차 업데이트

- 기본 달리기 260 → **306px/s (+17.69%)**, 달리기 애니메이션도 속도에 맞춤.
- 붓 획득 시 **459px/s (기본의 1.5배), 플레이 시간 10초**. 재획득은 시간만 10초로 갱신.
- 남은 가속 시간 표시, 일시정지 중 타이머 동결, 게임 오버/재시작 시 초기화.
- 귤은 36px 표시 영역으로 키우고 얇은 크림색 테두리 적용. 표시 좌표와 투명 여백을 반영한 수집 판정 사용.
- 추가로 그리던 옅은 나무·두루마리와 엽전 파티클 제거. 배경 원본의 그림은 유지.
- 점수 효과는 0.35초, 근접 획득 합산, 수명 연장 없이 정리.
- 일시정지 제목 **잠시 쉬어가게나**, 이어하기 **다시 달려보세!**, 재시작 **다시 도전하기**.

## 나무 장애물 리소스 미확보

`assets/obstacles`, `assets/extras`를 직접 확인했지만 그루터기·통나무 그림이 없습니다. 살아 있는 나무와 울타리는 다른 용도라 대체하지 않았습니다. **현재 버전에서는 장애물이 출현하지 않습니다.** 기차(귤 이미지 7·8), 바위·울타리·항아리도 더 이상 사용하지 않습니다.

충돌·체력·게임 오버 로직은 유지했습니다. `game.js`의 `WOOD_OBSTACLES.low/high`는 적합한 실제 파일이 확보될 때만 설정하도록 비워 두었습니다. 실물 그림에 맞는 크기/투명 여백/통과 여유 검증은 해당 원본이 있어야 완료할 수 있습니다. 게임 오버는 현재 일반 플레이에서는 도달하지 않으며, 테스트 전용 충돌 데이터로 회귀 검증합니다.

## 조작

- 시작하기 / Space로 시작
- Space / 화면 터치 / 모바일 점프 버튼: 최대 2단 점프. 착지하면 초기화
- 귤/귤 조각: 각 100점
- 붓: 10초 가속 (중첩 없이 갱신)
- 정지 버튼 / Esc: 일시정지와 이어하기. 탭 전환 시 자동 정지
- 일시정지와 결과 화면의 다시 도전하기: 전체 상태 초기화

## 패턴과 가속

평지 → 1단 아치 → 평지 → 2단 아치가 반복됩니다. 기본 속도에 맞춰 간격을 넓혔고, 공중 입력을 포함한 주요 수집 경로를 테스트했습니다. 붓은 일부 평지 패턴의 끝에 배치됩니다.

가속 중에는 수평 이동과 점프 물리에 같은 이동 시간 배율을 적용해 점프 **높이와 공간 궤적**을 유지합니다. 따라서 가속 중 체공 시간은 짧아지고 2단 입력도 더 빨라야 합니다. 가속 시작/만료 순간에 물체 위치나 캐릭터 높이를 순간 이동시키지 않습니다. 가속의 10초는 이 이동 시간이 아닌 실제 플레이 시간으로 계산합니다.

## 그림과 폰트

새 이미지를 생성하지 않았으며 PNG/HEIC 원본 파일을 변경하지 않았습니다. 테두리는 실행 중 Canvas의 원본 알파 실루엣으로만 그립니다. 로컬 파일 보안 정책 때문에 픽셀 읽기가 제한된 브라우저에서는 이미지 표시와 기본 수집 판정을 유지하고 간단한 하이라이트로 대체합니다.

감자꽃 손글씨는 SIL OFL 1.1이며 자체 호스팅합니다. 새 문구에 맞춰 WOFF2 문자 서브셋을 갱신했습니다. [출처 및 라이선스](assets/fonts/README.md).

## 남은 사항

- 적합한 나무 장애물 원본이 필요합니다. 실제 낮은/높은 나무 장애물 적용과 그림별 충돌 테스트는 보류 상태입니다.
- 원본 배경의 서로 다른 좌우 가장자리, 낮은 해상도 그림의 확대감은 유지됩니다.
- 실물 iOS/Android와 Safari는 미검증입니다.
